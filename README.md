# 現実をスワイプ

届いた〈現実〉を左右にスワイプして仕分け、あなたの「霧濃度」を判定する、スマホのブラウザ向けゲームです。
ドンデコルテさんの漫才「デジタルデトックス」に着想を得た、**非公式のファンアプリ**です。

## 遊び方

1. 「整理券を取って はじめる」を押す
2. 封筒（＝現実）が1通ずつ届くので仕分ける
   - **左にスワイプ**：現実をスワイプ（見なかったことにする）
   - **右にスワイプ**：向き合う
   - 下のボタンや、パソコンなら ← → キーでも仕分けできます
3. 12通仕分けると「霧濃度判定通知書」が届きます
4. X・LINE・コピーで結果をシェア

左に逃げるほど背景に霧がかかり、霧の教祖が「目覚めるな！」と褒めてくれます。

## ファイル構成

```
index.html      画面（タイトル／仕分け／判定結果）
css/style.css   見た目（昭和の役所 × ポップ）
js/content.js   文章まとめ（カード・教祖のセリフ・判定・シェア文）
js/app.js       動き（スワイプ・進行・判定・シェア）
```

ビルドや `npm install` は不要です。HTMLとCSSとJavaScriptだけで動きます。

## 手元で動かす

`index.html` をブラウザで開くだけで遊べます。
スマホから確認したいときは、同じWi-Fiで簡易サーバーを立てます。

```sh
npx serve .
```

## 公開する（GitHub Pages）

1. GitHub のこのリポジトリで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にする
3. **Branch** で公開したいブランチと `/ (root)` を選んで **Save**
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

シェアボタンのURLは、公開先のURLが自動で入ります。

## カードやセリフを増やす

`js/content.js` を編集するだけです。

- `CARDS` に1行足すとカードが増えます（`from` 差出人 / `subject` 件名 / `body` 本文 / `stamp` ハンコ）
- `DECK_SIZE` で1回に出る枚数を変えられます
- `GURU_LINES` が教祖のセリフ、`RANKS` が判定の称号と所見です

## 公開するときの注意

- 本人の写真・似顔絵・事務所のロゴは使っていません。追加しないでください
- 広告をつけるなど収益化する場合は、元ネタのフレーズの扱いを所属事務所に確認するのが安全です
