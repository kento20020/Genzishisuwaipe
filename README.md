# ゴビョー！

上にスワイプすると次々に出てくる、**5秒ミニゲームのショート**です。
YouTubeショートのように縦スワイプで次のゲームへ進み、ゲームによっては横スワイプで操作します。
見た目は昭和レトロ〜80年代のポップ（水玉、サンバースト、ドット文字、テレビのCM）です。

## 遊び方

1. タイトルから上にスワイプ（または「上にスワイプでスタート」を押す）
2. 「READY? → GO!」のあと、お題を5秒以内にクリア
3. 結果が出ると自動で次のゲームへ（ミスしたときは「もう一回」でやり直しも可能）
4. 連続クリアでCOMBOがのび、4COMBOごとに少しずつ難しくなる
5. 8ゲームごとに「CM」画面が入り、ベスト記録をX・LINEでシェアできる

ゲーム中の5秒間は縦スクロールが止まり、誤って次へ流れないようになっています。
パソコンでは ↑↓キーで移動、←→キー・スペースでゲーム操作ができます。

## 入っているゲーム（13種類）

| ゲーム | 操作 | 内容 |
|---|---|---|
| 連打 | タップ | 決められた回数をタップ |
| ピタッと止めろ | タップ | ストップウォッチを3.00秒で止める（難しくなると途中で数字が消える） |
| 仕分けろ | **横スワイプ** | ●は左、■は右に仕分ける |
| よけろ | **横スワイプ** | 3車線で落ちてくるブロックをよける |
| 押すな | なにもしない | 誘惑に負けずに5秒間さわらない |
| 色ちがい | タップ | 1枚だけ色がちがうタイルを探す |
| ど真ん中 | タップ | 動くメーターをまん中で止める |
| もぐらたたき | タップ | 穴から出てくるモグラを決められた数たたく |
| ふうせん | **長押し** | 押しているあいだふくらむ。線と線のあいだで指を離す |
| 早押し | タップ | ランプが赤になった瞬間にタップ（フライングはアウト） |
| 後出しじゃんけん | タップ | 「かて」「まけろ」「あいこ」のお題どおりに手を出す |
| キャッチ | **ドラッグ** | カゴを動かして落ちてくる★をキャッチ |
| おぼえて | **横スワイプ** | 一瞬見える矢印の順番をおぼえて、同じ順にスワイプ |

## ファイル構成

```
index.html      タイトル画面と上のスコア表示
css/style.css   見た目（色・柄・各ゲームの部品）
js/games.js     ミニゲームの一覧（ここに足すとゲームが増える）
js/app.js       縦スワイプのフィード、READY→GO→結果の進行、COMBO、CM画面、シェア
```

ビルドや `npm install` は不要です。

## ゲームを増やす

`js/games.js` の `GAMES` に1つ足すだけです。ファイル冒頭に、ゲームから使える道具（`g.onTap`、`g.onSwipe`、`g.frame`、`g.win` など）の説明があります。
タイマーや操作の受付は、ゲーム終了時に自動で片付きます。

調整用の数字は `js/app.js` の先頭にまとまっています。

- `DURATION`：制限時間（5000ミリ秒）
- `AUTO_NEXT_MS`：結果のあと自動で次へ進むまでの時間（0で自動送りなし）
- `CM_EVERY`：何ゲームごとにCM画面を挟むか

## 広告を入れるとき

8ゲームごとの「CM」画面が広告枠です。`js/app.js` の `createCmSlot()` の中、
「広告を載せるときは…」というコメントの位置に広告タグを置きます。

## 手元で動かす・公開する

- `index.html` をブラウザで開くだけで遊べます（スマホ確認は `npx serve .` などで）
- 収益化しない公開なら GitHub Pages、広告や課金をつけるなら Cloudflare Pages（無料・GitHub連携）がおすすめです
- ベスト記録はその端末のブラウザに保存されます（ログイン不要）
